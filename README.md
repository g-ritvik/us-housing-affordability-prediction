# US Housing Affordability Prediction

## Project Overview

This project uses machine learning to predict the percentage of households whose housing costs are at or below 30% of household income across U.S. ZIP codes.

It explores geographic, demographic, economic, and housing-related characteristics to estimate housing affordability and evaluate how well models generalize to previously unseen ZIP codes.

## Dataset Acknowledgment

This project uses the **Predicting Housing Affordability in the U.S.** competition dataset hosted on Kaggle.

- **Dataset:** [Predicting Housing Affordability in the U.S.](https://www.kaggle.com/competitions/predicting-housing-affordability-in-the-u-s)
- **Source:** Kaggle competition
- **Data access:** Downloaded directly from Kaggle by each user after accepting the competition rules.
- **Data included in this repository:** No raw competition datasets or sample submission files.

The competition data is not redistributed through this repository. Users must obtain the files through their own Kaggle accounts and comply with the competition's rules and applicable usage terms.

Cleaned datasets are generated locally by running the data-cleaning script. They are not included in the repository.

## Setup Instructions

### 1. Clone the Repository

```bash
git clone https://github.com/g-ritvik/us-housing-affordability-prediction.git
cd us-housing-affordability-prediction
```

### 2. Create and Activate the Conda Environment

This project uses a Conda environment named `housing-afford` with Python 3.12.

If Conda is not installed, install [Miniconda](https://docs.anaconda.com/miniconda/) or [Anaconda](https://www.anaconda.com/download).

From the repository root, open Anaconda Prompt or a terminal with Conda initialized.

Create the environment:

```bash
conda create -n housing-afford python=3.12 -y
```

Activate the environment:

```bash
conda activate housing-afford
```

Your terminal prompt should display `(housing-afford)`.

### 3. Install Dependencies

With the Conda environment activated, install the project dependencies:

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

### 4. Register the Jupyter Kernel

Register the environment as a Jupyter kernel:

```bash
python -m ipykernel install --user --name housing-afford --display-name "Python (housing-afford)"
```

When opening notebooks in VS Code:

1. Open the notebook.
2. Select **Select Kernel** in the upper-right corner.
3. Choose **Python (housing-afford)**.

Use this kernel for all project notebooks to ensure they use the correct environment and dependencies.

## Dataset Acquisition

### 5. Obtain the Competition Dataset

The competition data is not included in this repository. Each user must download it directly from Kaggle.

1. Create or sign in to your [Kaggle account](https://www.kaggle.com/).
2. Open the [competition page](https://www.kaggle.com/competitions/predicting-housing-affordability-in-the-u-s).
3. Review and accept the competition rules.
4. Generate a Kaggle API token from your account settings.
5. From the repository root, run:

```powershell
python -m src.data.data_download
```

6. Follow the script's instructions to configure Kaggle authentication.

The downloaded competition files will be placed under `data/raw/`. The required files include the training and test datasets. The sample submission file may also be downloaded for submission formatting.

Never commit or share Kaggle API credentials or competition data.

## Analysis and Modeling Workflow

### 6. Exploratory Data Analysis

Open and run:

```text
notebooks/01_eda.ipynb
```

This notebook explores the dataset's structure, distributions, relationships, and initial patterns. It also examines the target variable and potential predictors.

### 7. Data Quality and Imputation

Open and run:

```text
notebooks/02_data_quality_and_imputation.ipynb
```

This notebook investigates missing values, duplicate records, data inconsistencies, and potential imputation strategies.

### 8. Prepare the Clean Dataset

From the repository root, run:

```powershell
python -m src.data.clean_data
```

This script applies the finalized data-cleaning and preparation steps and generates the cleaned datasets under `data/clean/`.

These cleaned files are generated locally and are not included in the Git repository.

### 9. Baseline Model Development and Evaluation

Open and run:

```text
notebooks/03_baseline_model.ipynb
```

This notebook explores regression models, feature-selection approaches, preprocessing strategies, and model configurations.

It evaluates model performance using grouped cross-validation to prevent ZIP-code overlap between training and validation folds.

### 10. Final Model Comparison

From the repository root, run:

```powershell
python -m src.models.evaluate_models
```

This script compares the selected model configurations using the finalized feature set, preprocessing pipeline, and evaluation strategy.

It reports performance for previously seen and unseen ZIP codes and calculates the competition-weighted RMSE.

The comparison results are saved to:

```text
reports/model_comparison.csv
```

### 11. Train and Save the Final Model

Run:

```powershell
python -m src.models.train_model
```

This script trains the finalized Ridge Regression model using the complete cleaned training dataset and saves the fitted preprocessing and model pipeline to:

```text
artifacts/ridge_housing_affordability.joblib
```

The model artifact is generated locally and is not included in the repository.

### 12. Generate Predictions

Run:

```powershell
python -m src.models.predict_test
```

The prediction script loads the saved model artifact and provides two prediction modes:

- **Kaggle Test Predictions:** Generates predictions for the competition test dataset and saves the results under `reports/`.
- **Custom Prediction:** Accepts user-provided geographic, demographic, and housing-related characteristics to generate an area-level affordability estimate.

Generated prediction files are stored locally and are not distributed through the repository.
